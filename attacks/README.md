# Attack Simulation Framework

This directory contains adversarial simulation scripts designed to validate the resilience of the Secure Distributed ICS Platform.

The attack simulations model realistic threats targeting industrial telemetry systems and distributed operational technology environments.

## Simulated Attack Categories

- Sensor Spoofing
- Replay Attacks
- Flooding Attacks
- Data Tampering
- Unauthorized Node Access

## Objective

The purpose of these simulations is to validate:
- Authentication controls
- Integrity validation
- Replay protection
- Behavioral anomaly detection
- Availability protections
- Centralized logging

All attack simulations are intended strictly for educational and defensive security research purposes.
